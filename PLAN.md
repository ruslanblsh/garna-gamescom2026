# Gamescom 2026 Side Events — страница на garna.io

План разработки. Обновлён 30.07.2026 после разведки garna.io и Luma. Работаем в папке `garna-gamescom-events`.

## 1. Цель

Раздел на garna.io со всеми side-ивентами Gamescom (23–30 августа, Кёльн), на который ведём трафик из LinkedIn-рассылки вместо PDF. Требования из созвонов: контент тянется из Google-таблицы (обновление = вписать строку, без деплоя), переключение по дням, красивая кнопка Register вместо голой ссылки, внизу лёгкий оффер про payroll с CTA Book a demo. PDF остаётся параллельно для тех, кто боится ссылок. Язык — только английский, переключатель языков — заглушка.

## 3. Стек — разведка garna.io

Проверено в браузере: **garna.io собран на Astro + Tailwind**, не React/Next.

| Токен | Значение |
|---|---|
| Шрифт | **Manrope**, sans-serif |
| Фон body | `#101010` |
| Основной текст | `#a1a1aa` (zinc-400) |
| Заголовки | `#ffffff` |
| **Акцент** | **`#CBF300`** (кислотный лайм) |
| Акцент-подложка | `rgba(203, 243, 0, .08)` |
| Карточки | `rgba(255, 255, 255, .04)`, поверхность `#0c0c0c` |
| Линии | `rgba(255, 255, 255, .08)` |
| Хедер | `nav.garna-header fixed z-50 w-full top-0`, высота 65px, фон `rgba(5,5,5,.72)`, `backdrop-filter: blur(16px)`, снизу `1px solid rgba(255,255,255,.08)` |
| Футер | `footer.garna-footer pt-16 pb-16` |

**Важно:** наши лендинги (`garna-creators-landing`, `garna-offer-landing`) сделаны на Inter / `#070807` / `#a5ea16`. Это **не** палитра основного сайта. Раз страница живёт на garna.io и хедер с футером копируются 1:1, красим в токены garna.io: Manrope, `#101010`, `#CBF300`. Лендинги используем как источник паттернов (структура карточек, reveal-анимации, форма кнопок, page-glow), но перекрашиваем.

**Что отдаём (гибрид — оптимально для CDO):**

1. `index.html` — полностью рабочая standalone-страница с Tailwind через CDN, скопированными 1:1 хедером и футером garna.io и нашим блоком. Открывается двойным кликом, выглядит как прод. Для показа Владу и Андрею и для приёмки.
2. `section.html` — только основной блок (hero + навигатор + список + payroll-оффер), без хедера и футера. CDO вставляет его в свой Astro-layout между родными `<Header />` и `<Footer />`. Никакого переноса чужой вёрстки, никакого дубля компонентов.
3. `events-data.js` + `styles.css` + `script.js` — общие для обоих.

Размеры для справки: хедер garna.io — 22 210 символов HTML (много из-за dropdown-меню), футер — 7 428. Снимаем в начале кодинга через Chrome и сразу пишем в файл.

## 4. Референс: как это делает Luma

Смотрел календарные страницы Luma (`luma.com/discover`, страницы календарей). Их паттерн:

1. Шапка календаря: название + описание + Follow / Submit Event.
2. **Dot-grid месяца** — компактная сетка точек, где дни с ивентами подсвечены. Работает как визуальный навигатор и сразу показывает плотность недели.
3. Переключатель Upcoming / Past.
4. Вертикальный timeline: слева sticky-колонка с датой и днём недели, справа карточки — время, название, хост, локация, кнопка.

**Что забираем:** идею «плотность недели видна с первого взгляда» и вертикальный timeline с датой слева. **Что делаем иначе:** у нас всего 8 дней, поэтому вместо dot-grid месяца — горизонтальная лента дней с количеством ивентов на каждой кнопке. Это честнее показывает, что 25–27 августа самые плотные.

## 5. Структура страницы

1. **Header** — копия garna.io 1:1 (Products / Solutions / Resources с dropdown, Log In, Sign Up), все ссылки ведут на реальные страницы garna.io.

2. **Hero** — kicker `Gamescom 2026 · Cologne · 23–30 August`. H1, варианты:
   - **Your Gamescom 2026 Side Events Guide** ← рабочий фаворит
   - Every Side Event of Gamescom 2026 — in One Place
   - 105 Side Events. One Page.

   Подзаголовок: собрали каждый side-ивент недели, проверили ссылки, обновляем по ходу выставки. Строка статов: `105 events · 8 days · 1 city`. Две кнопки: скролл к гайду (акцентная) и Download PDF (вторичная). Ниже — тонкая строка «Last updated 30 July 2026», подтягивается из таблицы.

3. **Day navigator** — sticky-лента под хедером. Кнопки `Sun 23` … `Sun 30`, на каждой число ивентов; отдельно `All` и `TBA`. Активный день — заливка `#CBF300`, тёмный текст. Если пользователь открыл страницу в даты выставки — авто-выбор сегодняшнего дня, иначе 23 августа. Мобилка: горизонтальный скролл с fade по краям.

4. **Список ивентов дня** — timeline: слева время (`17:00–21:00`, tabular-nums), справа карточка. В карточке: название, описание, локация с иконкой, бейдж доступа, `access_note` мелким текстом, кнопка (`Register` / `Apply` / `Get tickets` / `Details` — по таблице выше). Featured-ивенты — обводка `#CBF300` и метка `Worth your time`. `closed` — карточка на 60% прозрачности. Внутри дня сортировка по времени.

5. **Payroll-блок** — в самом низу, лёгкая сноска, не продажа в лоб. Формулировка из созвона: *«Experiencing problems with payroll — or spending too much on it? Garna helps companies pay teams and contractors in 150+ countries.»* CTA **Book a demo**. Оформить карточкой на `rgba(203,243,0,.08)` с обводкой акцента.

6. **Footer** — копия garna.io 1:1: лого, Powered by MediaCube, языки, Terms / Privacy, LinkedIn, hello@garna.io, адрес, юридический дисклеймер GARNA LTD.

## 6. Этапы разработки (сессия с Opus)

1. **Скаффолд** — структура файлов, Tailwind CDN, токены garna.io, page-glow, контейнеры.
2. **Хедер и футер** — снять живой HTML с garna.io через Chrome, записать в файлы, вставить в `index.html`.
3. **Данные** — `events-data.js` (снапшот 105 строк) + `script.js`: fetch gviz, парсер, раскрытие multi-day по диапазону, группировка по дням.
4. **Навигатор и карточки** — рендер, бейджи, сортировка, featured, пустые состояния.
5. **Hero + payroll-блок** — финальный копирайт.
6. **Полировка** — мобилка, reveal при скролле, OG-теги и превью для шаринга в LinkedIn, фавиконки.
7. **Проверка** — прогон всех 105 ссылок на 200, валидность дат, скриншоты десктоп и мобилка.
8. **Handoff** — короткое ТЗ для Жени-дизайн (ClickUp, дедлайн 03.08), ссылку Владу.

## 7. Открытые вопросы

- **Куда ведёт Book a demo** — на garna.io кнопка без якоря. Форма, `hello@garna.io` или калькулятор? Нужен ответ до этапа 5.
- Финальный адрес страницы: `garna.io/gamescom-events` или `garna.io/en/gamescom-2026` — решает CDO с Владом.
- Открыть доступ к таблице по ссылке (Viewer) — без этого gviz не отдаст данные.
- Обновление PDF-версии в середине августа — вне скоупа страницы, но данные брать из той же таблицы.
